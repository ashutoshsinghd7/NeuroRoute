# 2-minute demo
1. (15s) Problem: wrong model = overpay, bad quality, or outage. Pitch: "Other routers optimise. We guarantee."
2. (20s) Click **Simple question**. Show the cheapest valid model and the trace.
3. (30s) Click **Primary model down**. A different valid model answers. Point at the lamp and the attempts.
4. (20s) Drag a latency slider above the budget. Send. Show "latency X > Y".
5. (20s) Click **Impossible**. Show the refusal and "Nothing was sent".
6. (15s) Click **Vague prompt**. Show the low-confidence flag.
7. (10s) History table and latency bars. Mention `pytest`.
